# 블로그 원고

기업교육 후기·칼럼 원고를 마크다운으로 관리합니다.

- 파일명: `YYYY-MM-DD-slug.md`
- 이미지: `assets/<slug>/` 하위에 저장 (가로 최대 1600px, JPEG 품질 82로 리사이즈)
- frontmatter의 `status` 값으로 상태를 구분합니다.
  - `draft` — 임시저장. 검수·승인 전이므로 게시하지 않습니다.
  - `published` — 발행 완료.

임시저장 원고 하단의 HTML 주석에는 발행 전 확인해야 할 체크리스트를 남겨 둡니다.
