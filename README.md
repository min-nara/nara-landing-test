# SpeakTime

영어 회화 학습 웹앱 (모바일 우선). **세는 것은 정답이 아니라 말한 시간입니다.**

듀오링고를 몇 달 해도 회화가 안 느는 이유는 분명합니다. 탭·선택형 문제는 재인(recognition)
기억만 키우고, 회화의 병목인 산출(production) — 아무것도 없는 상태에서 꺼내 쓰기 — 은
훈련되지 않기 때문입니다. 이 앱은 그 한 지점만 공격합니다.

## 설계 근거

| 기능 | 근거 |
|---|---|
| 같은 상황 반복 + 시간 압박 | 4/3/2 기법 — 반복할수록 발화 속도↑, 휴지·더듬음↓ (시간을 **줄이는** 조건이 고정 조건보다 효과적) |
| 청크 쉐도잉 | 유창한 화자는 통째로 저장된 덩어리에 의존. 명시적 청크 학습은 유창성을 유의하게 개선 |
| 대화 중엔 안 끊고, 끝난 뒤 명시적 교정 | 명시적 교정(d≈0.84) > 리캐스트(d≈0.53), 학습자 수정 반영률 50% vs 31% |
| 산출형 간격 반복 | 산출 지식은 재인보다 느리게 발달하며 3~4회 이상의 재학습을 요구 |
| 무판단 AI 상대 | 챗봇 대화는 말하기 불안을 낮추고 발화 의지를 높임. 한국 학습자는 정확성 중심 평가 탓에 침묵 경향이 강함 |
| "말한 시간"이 유일한 지표 | Nation의 Four Strands에서 듀오링고가 통째로 빠뜨리는 것이 유창성 훈련 |

## 한국어 구조대

이 앱의 핵심입니다. 말하다 막히면 **한국어로 말해버려도 됩니다.** AI가 그 자리에서 영어를
꽂아주고, 그 표현이 내 청크 덱에 쌓입니다.

듀오링고는 내가 *뭘 말하고 싶었는지* 영원히 모릅니다. "말하려다 못 한 것"이야말로 가장
필요한 학습 소재고, 그걸 수집하는 게 이 앱의 자산입니다. 부수 효과로 침묵 공포도 사라집니다.

## 세션 구조 (12분, 주 3~4회 기준)

```
1  상황 브리핑     모델 대화 듣기                ← 의미중심 입력
2  청크 쉐도잉     5개, 녹음·비교                ← 유창성·운율
3  롤플레이        무판단·안 끊음·한국어 구조대   ← 의미중심 출력
4  리포트          더 나은 표현 3개 (명시적)      ← 교정 피드백
```

간격 반복은 요일이 아니라 **세션 카운트** 기준(다음 / 3세션 후 / 7세션 후 …)입니다.
주 3~4회만 해도 스케줄이 무너지지 않습니다.

## 실행

```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev
```

### 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | 아니오 | [Google AI Studio](https://aistudio.google.com/apikey) 키. 없으면 **목업 모드**로 동작해 화면 흐름을 끝까지 확인할 수 있습니다 |
| `NEXT_PUBLIC_SUPABASE_URL` | 아니오 | 없으면 기록이 localStorage에만 남습니다 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 아니오 | 위와 동일 |
| `GEMINI_CHAT_MODEL` / `GEMINI_STT_MODEL` / `GEMINI_TTS_MODEL` | 아니오 | 모델 자동 선택을 덮어쓰고 싶을 때만 |

키를 꽂은 뒤 `GET /api/health` 로 **어떤 모델이 실제로 잡혔는지** 확인하세요.
모델 이름은 자주 바뀌므로 하드코딩하지 않고, 기동 시 사용 가능한 모델 목록에서 고릅니다.

### 음성 스택

STT·대화·TTS 모두 Google AI Studio 키 하나로 처리합니다.

- **STT** — Gemini 오디오 이해. 받아쓰기와 함께 채움말·1.5초 이상 멈춤·한국어 구간을 JSON으로 반환
- **대화** — Gemini Flash. 절대 교정하지 않고 대화만 굴립니다
- **TTS** — Gemini TTS. 말 속도를 제어할 수 있어 1차는 천천히, 2차는 정상 속도로 압박을 겁니다

녹음은 브라우저마다 포맷이 다르므로(Chrome webm/opus, iOS Safari mp4/aac) 클라이언트에서
16kHz 모노 WAV로 통일해 전송합니다.

## 데이터베이스

Supabase. board 앱과 프로젝트를 공유하므로 `speak_` 접두사로 격리했습니다.
스키마는 `supabase/migrations/0001_speak_schema.sql`.

로그인은 선택입니다. 안 하면 이 기기에만 기록되고, 매직링크로 로그인하면 기기를 바꿔도
청크 덱이 따라옵니다. 첫 세션부터 로그인 벽을 세우지 않는 게 중요합니다 — 말하기 앱에서
마찰은 그대로 '안 함'이 됩니다.

## 단계

- **1차 (현재)** — 음성 롤플레이 1회전 + 리포트 + 청크 적립. 시나리오 6개(일상 3 / 업무 3)
- **2차** — 2차 롤플레이(시간 -30%) + Before/After 재생 + 산출형 SRS 워밍업
- **3차** — 시나리오 30개, 쉐도잉 정밀 비교, 막힘 히트맵, 실전 전이 미션

`public/legacy.html` 은 이 저장소의 이전 정적 랜딩 테스트 페이지입니다.
